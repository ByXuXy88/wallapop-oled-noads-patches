# Attribution

These Wallapop patches were developed against the APK supplied by the user and the rushiranpise/morphe-patches source archive. They use Morphe's patch API and the bundle layout implemented by Morphe's patches Gradle plugin. The independent build downloads unmodified public tool distributions, checks pinned hashes, and compiles only the Wallapop source files. No tool distributions, Wallapop binaries, or user credentials are included in this repository.

Morphe is an upstream project name. This repository is named Wallapop OLED and No Ads and is not an official Morphe or Wallapop release. The source is distributed under GPL-3.0; upstream tool dependencies retain their own licences and terms.
